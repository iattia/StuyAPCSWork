# IDEAS:

**Proposal 1:**
* We will create a game in Processing similar to [Monopoly](https://www.gameflare.com/online-game/monopoly-online/), which will feature a full 40-slot board, a multiplayer feature on the same device, limited player customization, renditions of existing rules, and unique rules to the game itself. This includes a rent multiplier based on number of properties in a set, or potentially even a house-based multiplier for players who have a full set. This also includes a unique instant-bankrupt rule for any player which falls below $0, pushing players away from unnecesarily risky plays.

**Proposal 2:**
* We will create a game in Processing similar to Chess, which will feature an 8x8 checkered board, with features mainly taken directly from [chess.com](https://www.chess.com). All (or most) chess rules will be implemented. This includes check, checkmate, stalemate, en passant, 50-move, and other basic/easy-to-implement rules. More difficult rules to implement like three-fold repetition might not be implemented, depending on how long things take. More features include clicking on a piece highlighting legal moves, right-clicking squares to highlight or remove a highlight, and potentially adding a way to draw arrows with dragging a right-click if there is extra time.

**Proposal 3:**
* We will create a virtual escape room in Processing. We will have room(s) with mutliple objects scattered around and hidden in backgrounds. Some objects will be interactive and reveal a clue or hint. This information will allow the player to solve a puzzle and ultimately escape the room.
