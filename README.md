## Overview
We created create a game in Processing similar to [Monopoly](https://www.gameflare.com/online-game/monopoly-online/), which features a full 40-tile board, a multiplayer feature on the same device, limited player customization, renditions of existing rules, and unique rules to the game itself. This includes a rent multiplier based on number of properties in a set. This also includes a unique instant-bankrupt rule for any player which falls below $0, pushing players away from unnecessarily risky plays.
To play, select the number of players which you would like to play with, ranging from 2 to 4 players. From there, you could select custom colors for each player. Once you start, players will roll their dice and try to balance their game in properties and balance. Once a player goes below $0, they instantly lose and are out of the game. Last player wins.
